## ✨ Fitur Utama HEAL App

- 🚑 **Panggilan & Permintaan Ambulans PSC 119**: Sistem evakuasi darurat medis resmi Kemenkes RI dengan integrasi pelacakan titik lokasi GPS (Google Maps) otomatis dan panggilan langsung ke nomor hotline 119.
- 🏥 **Bank Penyakit**: Ensiklopedia penyakit fisik & mental dengan kategori lengkap (Kardiovaskular, Pernapasan, Mental, Pencernaan, dll.) beserta gejala, obat yang dianjurkan, pantangan, dan pencegahan.
- 🩺 **Cek Gejala (Symptom Checker)**: Diagnosa awal berbasis pemilihan gejala interaktif dengan peringatan gawat darurat medis.
- 🎭 **Mood Tracker & Daily Wellness**: Pencatatan suasana hati harian, afirmasi positif, pelacak hidrasi air minum (water counter), dan jam tidur.
- 🗣️ **Voicing Rights**: Forum berbagi cerita dan curhat anonim antar-remaja dengan sistem reaksi empati (`🫂`, `💙`, `🔥`) dan chat konseling.
- 💬 **Inspirational Quotes**: Generator kutipan motivasi harian dengan fitur unduh gambar ber-watermark HEAL dan Web Share API.
- 🌬️ **Calm Corner**: Relaksasi pernapasan terpandu teknik 4-7-8 dengan animasi visual interaktif.
- 🔐 **Autentikasi & Profil**: Terintegrasi penuh dengan Firebase Firestore, mendukung foto avatar, bio, sekolah asal, dan media sosial.

## 🚀 Menjalankan Project

### 1. Prasyarat
- Node.js (v18 atau lebih baru)
- NPM

### 2. Instalasi Dependensi
```bash
npm install
```

### 3. Menjalankan Server Lokal (Dev)
```bash
npm run dev
```

### 4. Build & Sinkronisasi ke Android (Capacitor)
```bash
npm run build
npx cap sync
```
